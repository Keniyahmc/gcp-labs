# 🗄️ Lab 02: Introduction to SQL for BigQuery and Cloud SQL

## Overview
Learned SQL fundamentals using BigQuery on the London bikeshare
public dataset. Exported data to CSV, uploaded to Cloud Storage,
and used Cloud SQL to create databases, tables, and run advanced
queries.

## Objectives
- ✅ Run SQL queries in BigQuery on a public dataset
- ✅ Use SELECT, FROM, WHERE, GROUP BY, COUNT, AS, ORDER BY
- ✅ Export query results to CSV and upload to Cloud Storage
- ✅ Create a Cloud SQL instance, database, and tables
- ✅ Load CSV data into Cloud SQL tables
- ✅ Run advanced queries using DELETE, INSERT INTO, and UNION

## What I Learned
- BigQuery can query petabyte-scale datasets with standard SQL
- GROUP BY returns unique values and COUNT shows matching rows
- Cloud SQL is a managed relational database that accepts CSV imports
- UNION combines results from multiple SELECT queries into one output
- DELETE removes rows matching a condition not just the first row
