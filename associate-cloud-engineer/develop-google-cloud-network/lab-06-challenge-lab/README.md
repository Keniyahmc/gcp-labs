# 🏆 Lab 06: Develop Your Google Cloud Network - Challenge Lab

## Overview
Helped the Griffin team set up their development environment on
Google Cloud. Created development and production VPCs, a bastion
host, Cloud SQL instance, Kubernetes cluster, and deployed a
WordPress application with monitoring enabled.

## Tasks Completed
- ✅ Create development VPC manually
- ✅ Create production VPC manually
- ✅ Create bastion host
- ✅ Create and configure Cloud SQL Instance
- ✅ Create Kubernetes cluster
- ✅ Prepare the Kubernetes cluster
- ✅ Create a WordPress deployment
- ✅ Enable monitoring
- ✅ Provide access for an additional engineer

## What I Learned
- Custom VPCs require manually creating subnets unlike auto mode
- A bastion host with multiple NICs bridges two isolated VPCs
- Cloud SQL secrets must be configured before Kubernetes deployments
- WordPress on Kubernetes requires both a deployment and service YAML
- Uptime checks and IAM access management are core DevOps practices
