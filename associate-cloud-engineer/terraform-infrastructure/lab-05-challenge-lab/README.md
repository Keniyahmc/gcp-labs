# 🏆 Lab 05: Build Infrastructure with Terraform - Challenge Lab

## Overview
Imported existing VM instances into Terraform, built custom
modules, configured a Cloud Storage remote backend, used a
Registry module to create a VPC with subnets, and added a
firewall rule to allow connections between instances.

## Tasks Completed
- ✅ Create the configuration files
- ✅ Import infrastructure
- ✅ Configure a remote backend
- ✅ Modify and update infrastructure
- ✅ Destroy resources
- ✅ Use a module from the Registry
- ✅ Configure a firewall

## What I Learned
- Terraform modules organize and reuse infrastructure configuration
- Importing existing resources requires manual config writing
- Remote backends enable team collaboration and prevent corruption
- Registry modules enforce best practices for common infrastructure
- Resource dependencies are handled automatically via module outputs
- Firewall rules can reference network self_link from state
