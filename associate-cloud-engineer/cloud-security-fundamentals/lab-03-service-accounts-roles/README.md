# 🤖 Lab 03: Service Accounts and Roles - Fundamentals

## Overview
Created and managed service accounts, granted IAM roles, and
used a service account on a VM to query BigQuery using Python.

## Objectives
- ✅ Create and manage service accounts
- ✅ Grant IAM roles to a service account
- ✅ Create a VM with a service account attached
- ✅ Use Python client libraries to query BigQuery

## What I Learned
- Service accounts grant permissions to apps and VMs not users
- VMs use attached service accounts to access GCP APIs securely
- Python client libraries use compute_engine.Credentials automatically
- Least privilege means only granting roles needed for the task
