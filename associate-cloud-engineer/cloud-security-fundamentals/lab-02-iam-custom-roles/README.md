# 🛠️ Lab 02: IAM Custom Roles

## Overview
Created, updated, disabled, deleted, and restored custom IAM
roles using both YAML files and CLI flags.

## Objectives
- ✅ View available permissions for a resource
- ✅ Create custom roles using YAML and CLI flags
- ✅ Update, disable, delete, and restore custom roles

## What I Learned
- Custom roles enforce least privilege with only needed permissions
- Permissions are formatted as service.resource.verb
- Deleted roles can be restored within 7 days
- Disabling a role inactivates bindings without deleting it
