# 🏆 Lab 08: Implement Cloud Security Fundamentals - Challenge Lab

## Overview
Applied all skills from Labs 01-07 independently to configure
a secure Kubernetes Engine private cluster for the Orca team
using a dedicated service account with least privilege.

## Tasks Completed
- ✅ Create a custom security role
- ✅ Create a service account
- ✅ Bind IAM security roles to the service account
- ✅ Create and configure a private Kubernetes Engine cluster
- ✅ Deploy an application to the private cluster

## What I Learned
- Custom IAM roles enforce least privilege
- GKE clusters need monitoring and logging roles at minimum
- Private clusters can only be accessed from within the VPC
- A jumphost is required to manage a fully private cluster
